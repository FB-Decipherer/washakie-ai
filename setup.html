Setup

The sheet that produces a page. Nothing here is a login and nothing here is protected, because there is nothing behind it to protect — it is a form that writes files. Fill it in, copy the output, paste it into the file, publish.

D1Page header

A standing page can leave the date blank. A running series must set it: the date then appears in four places and all four must agree, and this sheet writes all four from the one field.

Today's claim
One day's progress, presented three ways.



D2Front image


Which picture heads the page. Type the file names that are sitting in the issue folder, one per line; the chooser lists them and shows what you picked. Captions are set at 22px, larger than body text, because a caption is often the only thing a scanning reader reads.













D3References


One card per external source. Order is fixed: kind, title, provenance, preview, why it is cited, then the link last. The link goes last on purpose — put it first and readers click it before reading the preview, which defeats the whole column.









D4Link health


A browser cannot test somebody else's link — a cross-origin request comes back with no status attached, so an in-page checker reports healthy links as dead. The check therefore runs on a schedule, away from the reader, and writes the small file below. Tick anything known dead and give the date it was found.









If in doubt, leave it empty. A missing or empty links.json makes the page say nothing at all about link health. That is the correct default: no file means no claim, and never a false alarm.
